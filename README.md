# Мониторинг строительных работ
Решение команды Data Squad на хакатоне Цифровой Прорыв в Екатеринбурге.

# Описание технического решения
Сначала поделили на 5минутные кусочки из основного видео, данного кейсодержателями, после чего отобрали самые важные и разметили 200 минут в программе VIAME DIVE desktop. Особенности разметки в том, что выделяем дополнительные классы техники и обозначаем через нижнее подчеркивание простой\работу или же неизвестность техники.
После чего обогатили датасет прямыми трансляциями со стройки с YouTube, таким образов увеличив его на 150 минут.
Чтобы наша модель машинного обучения правильно определяла классы, применили различные аугментации.

С помощью скрипта поделили на 3секундные ролики действия или же бездействия машины для обучения классификатора.


Реализовали сайт для детекции классов, простоя или же работы техники в режиме реального времени или с помощью записанного видео.

Также у нас есть MVP приложение, основанное на PyQT.
