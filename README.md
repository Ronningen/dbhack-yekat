# Мониторинг строительных работ
Решение команды Data Squad на хакатоне Цифровой Прорыв в Екатеринбурге.

# Описание технического решения
Наше решение формирует события появления в обзоре камеры и работы спец.техники следующим образом: сначала детектор находит на каждом кадре спец.технику и классифицирует ее; далее трекер соединяет результаты детекции в последовательность, определяя путь одной единицы техники, автоматически назначая начало и конец события как начало и конец трека; наконец видео-классификатор определяет работает ли техника или простаивает для каждой маленькой подпоследоватетельности кадров из трека, расставляя события смены активности.

Тех.особенности: yolov8, (pytorchvision, slowfast, videomae, mvitv2), (pyqt6, aiohttp & aiortc).

Уникальность: наше решение описывает происходящее в кадре в каждый момент видео, расширяя возможности анализа; позволяет в реальном времени анализировать видеопоток с камер или стрим с видеохостинга.

Датасет: удалось сформировать датасет суммарно в 6 часов видео-роликов из разнообразных источникв (из ютуба и от организаторов хакатона)

# Install
## MacOS & Linux
```
git clone https://github.com/Ronningen/dbhack-yekat
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
## Windows

```
git clone https://github.com/Ronningen/dbhack-yekat
python -m venv .venv
.venv/Scripts/activate
pip install -r requirements.txt
```

# Runtime
Для запуска десктоп приложения:
```
python3 app/desktop.py
```
Загрузите видео, дождитесь обработки и скачайте .json


Для запуска серверного приложения (доступен стриминг из ютуба)
```
python3 app/web/server.py
```
И перейдите по ссылке http://127.0.0.1:8080
