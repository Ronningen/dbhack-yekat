# Мониторинг строительных работ
Решение команды Data Squad на хакатоне Цифровой Прорыв в Екатеринбурге.

# Описание технического решения
Сначала поделили на 5минутные кусочки из основного видео, данного кейсодержателями, после чего отобрали самые важные - отобрано 14  статических сцен с разным уровнем освещенности и 20 динамических с работающей строительной техникой и разметили **170 минут** в программе VIAME DIVE desktop. Особенности разметки в том, что выделяем дополнительные классы техники и обозначаем через нижнее подчеркивание простой\работу или же неизвестность техники. После чего обогатили датасет прямыми трансляциями еще 32 отрезка собранных из открытых источников с 5 разных строительных локаций, таким образов увеличив его на **160 минут**. Итоговый датасет для  обучения детектора составил **40 тыс изображений** (3 кадра в сек).

Чтобы наша модель машинного обучения правильно определяла классы, применили различные аугментации.


Реализовали сайт для детекции классов, простоя или же работы техники в режиме реального времени или с помощью записанного видео.

Также у нас есть ещё одно MVP - это приложение, основанное на PyQT.
