Запустите сервер:

.. code-block:: console

    $ python server.py

Теперь в можете зайти на сайт по порту:

http://127.0.0.1:8080

В поле с ссылкой можете вставить ссылку на произвольный стрим, нажмите на появившуюся в плеере ниже кнопку плей, тогда видео с постобрабокой будет транслироваться на сатй
